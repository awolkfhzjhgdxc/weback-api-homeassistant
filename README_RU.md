# WeBack Vacuum для Home Assistant

Пользовательский компонент (Custom Component) для Home Assistant с полной поддержкой роботов-пылесосов экосистемы WeBack / Grit Cloud (включая Tesvor, Redmond и др.).

[English version (README.md)](README.md)

---

## Возможности
- **Полное управление роботом-пылесосом**: запуск уборки, пауза, остановка, возврат на зарядную базу, поиск устройства звуковым сигналом, выбор мощности всасывания (тихий, стандартный, мощный).
- **Отображение карты в реальном времени**: сущность камеры `camera.<имя_пылесоса>_map`.
- **Отрисовка траектории и позиции**: динамическое построение карты с отображением пройденного маршрута, убранной зоны и текущей позиции робота.
- **Поддержка протокола Grit Cloud v2**: авторизация OAuth 2.0 и защищённый обмен командами по WebSocket (WSS).
- **Удобная настройка через интерфейс**: интеграция настраивается через стандартный Config Flow в меню Home Assistant на русском языке.

## Установка

### Вариант 1: Автоматический скрипт установки (рекомендуется)
Склонируйте репозиторий или скачайте его на хост с Home Assistant и запустите:
```bash
./install.sh
```
Если Home Assistant установлен в нестандартный каталог, укажите путь:
```bash
./install.sh /var/lib/homeassistant/homeassistant
# или
./install.sh /config
```

### Вариант 2: Ручная установка
1. Скопируйте папку `custom_components/weback_vacuum` в вашу директорию `<config>/custom_components/`.
2. Перезагрузите Home Assistant.

## Настройка после установки

### Шаг 1. Перезагрузка Home Assistant
После копирования файлов обязательно перезапустите сервер Home Assistant:
- Через веб-интерфейс: **Настройки** -> **Система** -> **Перезагрузить Home Assistant**.
- Либо через консоль: `systemctl restart homeassistant` или `ha core restart`.

### Шаг 2. Добавление интеграции
1. В Home Assistant перейдите в **Настройки** -> **Устройства и службы** (**Devices & Services**).
2. Нажмите кнопку **«Добавить интеграцию»** (синий плюс в правом нижнем углу).
3. В поиске введите **WeBack** (или **Tesvor**) и выберите **WeBack/Tesvor Vacuum**.
4. Заполните форму подключения:
   - **Имя пользователя / Email**: email или телефон, на который зарегистрирован аккаунт в приложении WeBack / Tesvor.
   - **Пароль**: пароль от вашего аккаунта.
   - **Регион**:
     - `7` — для России, Европы и стран за пределами Китая (International).
     - `86` — для Китая (China).
   - **Язык**: `ru` (русский) или `en` (английский).
   - **Приложение**: выберите `WeBack` (или `Redmond`, если пылесос зарегистрирован в приложении Redmond).
   - **Client ID**: оставьте значение по умолчанию `yugong_app`.
   - **Версия API**: оставьте значение по умолчанию `1.0`.
5. Нажмите **Отправить**. Интеграция свяжется с сервером Grit Cloud, получит токен и создаст устройства:
   - Сущность пылесоса: `vacuum.<имя_пылесоса>`
   - Сущность карты: `camera.<имя_пылесоса>_map`

## Настройка дашборда Lovelace

### Карточка управления пылесосом
Добавьте стандартную карточку пылесоса:
```yaml
type: vacuum
entity: vacuum.robot
name: Робот-пылесос
```
*(Замените `vacuum.robot` на ID вашей сущности)*

### Карточка живой карты (Live Map)
Для отображения карты с автоматическим обновлением используйте карточку `picture-glance` или `picture-entity`:

```yaml
type: picture-glance
title: Карта уборки
camera_image: camera.robot_map
camera_view: live
entities:
  - entity: vacuum.robot
```

Или простая карточка изображения:
```yaml
type: picture-entity
entity: camera.robot_map
name: Текущая карта
camera_view: live
show_state: false
```

При запуске уборки карта будет автоматически обновляться по мере перемещения робота по комнатам.

## Протестированные устройства
- **REDMOND RV-R670S** — полное тестирование функционала: авторизация через Grit Cloud OAuth, управление движением и мощностью, получение статусов батареи и ошибок, динамическая отрисовка карты по лидару (`camera.*_map`).
- Совместимо с другими моделями экосистемы WeBack / Grit Cloud (Tesvor, Redmond, Mamibot, Neatsvor и др.).
